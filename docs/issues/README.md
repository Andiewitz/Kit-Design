# Issues

Use this directory for reproducible bugs, regressions, and follow-up work that is not yet captured in a plan.

## Naming

`YYYY-MM-DD-short-slug.md`

## Required fields

- Status: open, investigating, blocked, or resolved
- Severity: low, medium, high, or critical
- Area: `client/app`, `client/web`, `services`, or `tooling`
- Clear reproduction steps and expected behavior
- Impact and any known workaround

Start from [`_template.md`](_template.md). Once an issue is resolved, add the fix, validation steps, and links to the relevant commit or pull request.
